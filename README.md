# Planificación de 6.º de Primaria — CAJPD

Sitio estático listo para GitHub Pages. Subir `index.html` y las carpetas `css`, `js`, `assets` a la raíz del repositorio. En Settings > Pages seleccionar Deploy from a branch / main / root.

Proyecto del período 1: «El perrito perdido», Scratch MIT. 8 sesiones de 90 minutos. Rúbrica de 100 puntos, fichas imprimibles y registro local. Períodos 2–4 propuestos, pendientes de validación curricular.

**Importante:** El registro se guarda con localStorage en el navegador, no en la nube. Para respaldo, usar Descargar registro.
